# documentation

Purpose:
Create accurate project documentation.

Instructions:
- Inspect actual implementation before documenting it.
- Keep README/setup instructions synchronized with the repository.
- Verify commands before documenting them.
- Verify environment variables.
- Verify APIs/endpoints.
- Verify configuration.
- Explain installation, development, testing, and deployment clearly.
- Never document functionality that does not exist.
- Clearly distinguish required configuration from optional configuration.
- Prefer practical examples.
