# git-workflow

Purpose:
Safely manage Git status, branches, commits, diffs, and change preparation.

Instructions:
- Check git status before significant work.
- Check the current branch before changing anything.
- Preserve existing uncommitted user changes.
- Review diffs before committing.
- Keep commits focused.
- Use clear commit messages.
- Run relevant tests before committing when practical.
- Never discard existing work without explicit instruction.
- Never force-push without explicit instruction.
- Never rewrite Git history unless explicitly requested.
- Never mix unrelated changes into a commit.
