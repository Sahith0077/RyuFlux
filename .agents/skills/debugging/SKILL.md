# debugging

Purpose:
Systematically diagnose bugs, errors, crashes, failing tests, and unexpected behavior.

Instructions:
- Reproduce the problem first.
- Capture the exact error/output.
- Identify the first meaningful failure rather than blindly fixing later symptoms.
- Trace the failure to the responsible code/configuration.
- Form a concrete hypothesis.
- Make the smallest appropriate fix.
- Re-run the relevant command/test.
- Check for regressions.
- Explain root cause, fix, and verification.
- Never randomly modify multiple unrelated files.
- Never hide errors just to make the application appear functional.
- Never remove useful error handling merely to silence warnings.
