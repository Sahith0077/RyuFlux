# project-onboarding

Purpose:
Understand an unfamiliar project before making changes.

Instructions:
- Inspect the repository structure.
- Identify the language and framework only from actual files.
- Inspect package/dependency files.
- Inspect configuration files.
- Identify application entry points.
- Identify database/API/frontend/backend structure if present.
- Inspect README and existing documentation.
- Inspect tests.
- Inspect environment/configuration files without exposing secrets.
- Identify build, test, lint and run commands from the repository.
- Summarize the architecture before making major changes.
- Never invent technologies, files, APIs, or architecture.
- Never make major modifications before understanding the existing structure.
