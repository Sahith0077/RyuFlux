# code-review

Purpose:
Review code for correctness, maintainability, security, performance, and architectural issues.

Review in this order:
1. Correctness
2. Bugs
3. Security
4. Data integrity
5. Error handling
6. Performance
7. Edge cases
8. Maintainability
9. Duplication
10. Naming/readability
11. Architecture
12. Test coverage

For every real issue provide:
- Severity
- File/location
- Problem
- Why it matters
- Recommended fix

Do not report trivial stylistic preferences as major problems.
