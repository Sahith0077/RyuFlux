# Coding Standards

- Clear naming.
- Small focused functions/classes.
- Avoid unnecessary duplication.
- Meaningful comments only.
- Keep functions reasonably focused.
- Handle errors explicitly.
- Prefer readability over cleverness.
- Follow the existing project's conventions when they are established.
- Do not perform huge refactors without a clear reason.
